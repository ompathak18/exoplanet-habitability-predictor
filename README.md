# 🚀 Exoplanet Habitability Predictor

A machine learning web app that predicts whether an exoplanet could support life using NASA-inspired planetary data.

## 🌌 Features
- Predict planet habitability
- Interactive galaxy visualizations
- Design your own planet
- Compare planets with Earth
- Modern space-themed UI

## 🛠️ Built With
- Python
- Streamlit
- Scikit-learn
- Pandas
- Plotly

## 🚀 Live App
https://exoplanet-habitability-predictor-du2hk6oxo9hsvbuvwvhu3v.streamlit.app/

## ▶️ Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
